# Smash - Mini Shell Implementation  

This repository contains the implementation of **Smash**, a minimal shell created as part of coursework at the Technion. The project involved designing and implementing a custom shell capable of executing commands, handling processes, and managing threads effectively.  

## Features  
- **Command Parsing**: Supports basic shell commands.  
- **Thread Management**: Efficient handling of concurrent tasks and synchronization.  
- **Process Control**: Execution and monitoring of background and foreground processes.  

## Challenges  
The main challenges faced during this project included:  
- Proper thread handling and synchronization.  
- Efficient management of process lifecycles.  
- Ensuring stability and responsiveness in a multithreaded environment.  

## Usage  
Clone this repository and follow the instructions in the source files to compile and run the shell.  

```bash  
git clone https://github.com/MeirFriedmann/smash.git  
cd smash  
make  
./smash  
```  

Enjoy exploring the mini shell! 😊
